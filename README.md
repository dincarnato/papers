# Papers from the IncaRNAto lab
This repository hosts datasets, scripts &amp; pipelines associated with papers from the IncaRNAto lab

- __Borovska *et al.*, 2025__. Contains the __DeConStruct__ pipeline for identifying putative RNA structural switches using chemical probing data and evolutionary information (PMID: [40715458](https://pubmed.ncbi.nlm.nih.gov/40715458/)).
- __Zhang *et al.*, 2026__. Contains the __diffShape__ method for calling structurally-disrupted RNA regions upon small molecule treatment (PMID: [41872169](https://pubmed.ncbi.nlm.nih.gov/41872169/)).
